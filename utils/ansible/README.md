## Prerequisites

- [docker](https://docs.docker.com/) installed

## Build

To build ansible docker image, execute the following script:
```bash
./build.sh
```

## Run

To run ansible docker image, execute the following script:
```bash
./run.sh
```

## Exit

To exit container, execute:
```bash
exit
```
