# Kibana util

## Author
Witold Krak, emial: witold.krak@gmail.com

## Prerequisites

- [docker](https://docs.docker.com/) installed
- Docker container kibana.util up and running

## Build script

To build kibana docker image, execute the following script:
```bash
./build.sh
```

## Run script

To run kibana docker container, execute the following script:
```bash
./run.sh
```
